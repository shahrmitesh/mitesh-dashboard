# mitesh-dashboard

Public mirror of Mitesh's unified OS dashboard, hosted via GitHub Pages
for a live clickable link.

**Source of truth for edits:** the private repo `shahrmitesh/mitesh-os`.
This repo exists only to serve `index.html` (a copy of `dashboard.html`)
via GitHub Pages, since Pages requires a public repo on the GitHub Free
plan.

Contains store/GM/financial/personal data — public and viewable by
anyone with the link, by design (Mitesh's choice, 2026-08-01).
